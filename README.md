# Lecture 4 – HTML, CSS and Sass

This repository contains practical examples from the TSI University Web Application Development Technologies Lecture 4 classwork.

## Sass Examples

1. **Variables** – Using variables for fonts and colors.
2. **Nesting** – Nesting CSS selectors inside parent selectors.
3. **Partials** – Creating reusable SCSS files.
4. **Import** – Importing `_reset.scss` into the main stylesheet.
5. **Mixins** – Using `@mixin` and `@include` for border radius.
6. **Extend/Inheritance** – Sharing styles using `@extend`.
7. **Operators** – Performing mathematical calculations in Sass.

## Technologies

- HTML5
- CSS3
- Sass (SCSS)
- GitHub Codespaces
